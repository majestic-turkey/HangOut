
# HangOut

## Description
A multiplayer version of Hangman using websockets.

## Features
- Random words and user-submitted words are allowed
- Persistence of game and user records
- Stretch goal: Allow multiple simultaneous games and game saving

## Installation
```bash
# Clone the repository
git clone https://github.com/majestic-turkey/HangOut.git

# Navigate to project directory
cd HangOut

# Install dependencies
npm install
```

## Usage
```bash
# Start in development mode
npm run dev

# Equivalent
npm start
```
